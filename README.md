# Nahook Homebrew tap

Auto-published Homebrew formulas for [Nahook](https://nahook.com) CLI tools.

## Install

```sh
brew install getnahook/tap/nahook
```

The formula is auto-generated by [goreleaser](https://goreleaser.com) on
each tagged release in the
[nahook-cli](https://github.com/getnahook/nahook-cli) repo.
